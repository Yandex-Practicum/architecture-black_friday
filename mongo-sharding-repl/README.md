# Задание 3: mongo-sharding-repl

Репликация для каждого шарда и конфигурационного сервера (по 3 реплики в каждом реплика-сете).

## Как запустить

* запуск контейнеров
```shell
docker compose up -d
```

* запуск скрипта с командами
```shell
./scripts/mongo-init.sh
```

* приложение будет доступно на http://localhost:8080
